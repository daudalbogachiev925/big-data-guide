## 4. Как пользоваться этим репозиторием

1. Изучите раздел **Общие списки** — там собраны сотни ссылок на инструменты.
2. Для обучения начните с **data-engineering-zoomcamp**.
3. Если нужен конкретный фреймворк — переходите в раздел **Исходники**.
4. Все ссылки ведут на официальные репозитории GitHub.
